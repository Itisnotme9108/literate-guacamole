# Editorial Resort & Swimwear — Handmade Crochet Storefront

An artisanal e-commerce storefront specializing in handmade crochet swimwear, bikinis, one-piece swimsuits, resort cover-ups, and beach accessories. Built using pure HTML5, CSS3, and vanilla JavaScript.

## Features
- **Independent Sizing Engine**: Dual top and bottom size selection for set products before enabling Add to Bag.
- **Product Detail Quick View**: Surfaces lining status, stretch & fit guidance, care instructions, and made-to-order turnaround notices.
- **Seasonal Capsule Drops**: Filter products by seasonal collections (e.g. Amalfi Coast '26, Sienna Sunset).
- **Custom Swim Fit Inquiry**: Bespoke measurement submission form collecting Bust, Underbust, Waist, and Hip dimensions in inches with structured `mailto:` fallback.
- **Slide-Out Shopping Bag**: Persistent cart state via `localStorage` (`crochet_swim_cart_v1`) and Stripe Payment Link hooks.
